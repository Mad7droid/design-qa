# Hyper Spec privacy site

Buildless public privacy-policy page. Serve `dist/` with any static host. The root and `/privacy/` routes contain the same policy, with a contact anchor at `#changes-and-contact`.

Live page: https://hyper-design-qa-privacy.mad7droid.chatgpt.site/privacy/

The site has no scripts, analytics, external fonts, or extension review data. The policy text is maintained in `release/privacy-policy.md`. The hosting connection has a separate managed source checkout, excluded from this GitHub repository to avoid publishing credentials or nested Git metadata.
